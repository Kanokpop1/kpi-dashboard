ติดตามตัวชี้วัดโรงไฟฟ้า BLG / BST

เดือน
เกณฑ์สถานะ: SR และ GWEAF/EAF ผ่านเมื่อค่าจริง ≥ เป้า · UOR และชั่วโมงหยุดเครื่อง (POH, UOH, MOH, FOH) ผ่านเมื่อค่าจริง ≤ เป้า · POH, UOH, MOH และ FOH เป้า 0 ถือเป็นเป้าหมาย (ผ่านเมื่อไม่มีชั่วโมงหยุดเลย) · SR, UOR และ GWEAF/EAF ที่เป้าเป็น 0 หรือว่างแสดงเป็น "ไม่มีเป้า" · ข้อมูลประวัติหยุดเครื่องเป็นของ BLG
